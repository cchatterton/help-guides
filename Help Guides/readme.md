# Help Guides (Wiki-style)

Author: TECHN
Version: 1.2.1
Status: Production

## Purpose

Provides the established Wiki Pages admin interface and contextual help-guide features.

## Key Features

- Wiki Pages browser and editor
- Screen-specific help tabs
- CSS class-targeted inline guides
- Original magenta information-icon branding
- Native GitHub updates

## Folder Structure

The main file is `help_guides.php`; existing runtime modules and the GitHub updater are in `includes/`.

## Important Notes

Advanced Custom Fields Pro is required for guide mappings. Version 1.2.1 intentionally preserves version 1.1 behaviour.

## Future Considerations

Behavioural changes require a separate tested release.
