# TN Help Guides

Author: Techn
Version: 1.2.0
Status: Production

## Purpose

Wiki-style WordPress admin documentation with contextual and inline help.

## Key Features

- Hierarchical guide browser
- Screen-specific help tabs
- Accessible inline help popovers
- Existing `wiki` content and ACF field compatibility
- Native, manifest-first GitHub updates

## Folder Structure

Runtime PHP is in `functions/`, presentation is in `templates/`, and scoped assets are in `scripts/` and `styles/`.

## Important Notes

Advanced Custom Fields Pro is required for mappings and inline targets. Remove the old version 1.1 plugin folder before installing this standards-compliant package.

## Future Considerations

Large guide libraries may benefit from indexed screen and URL mappings.
